## 3. Issues?

### 3.1 Validation 的 per-sigma 诊断数值不可用

日志里 `val_aa_ce_sigma_lt_0p1=0.09044`、`val_aa_acc_sigma_lt_0p1=0.002782` —— CE 0.09 对应
p(true)≈0.91，与 0.28% 的 accuracy 数学上无法并存。

根因：`loss.py:_aa_sigma_diagnostics` 对空桶 `continue`（第 393 行），因此稀疏 sigma 桶只在
少数样本上产生 key；而 `trainer.py:790` 的 `evaluate()` 用**同一个全局 `count`**
（= 验证集样本数 128）去除所有 key。训练侧没有这个问题——`trainer.py:856` 用的是
per-key 计数 `train_metric_counts[key]`。

实测：step 2000 时 128 个验证样本中只有 **4 个**有 `lt_0p1` 桶，其真实值为
CE 2.861–2.941、acc 0.056–0.136；4 项之和除以 128 恰好复现日志里的 0.09044 / 0.002782 / 11.67。
